Help & Documentation

🔔 Bell Controls: Click Bell 1-7 to test sounds. Adjust volume with the slider (0-30).

⏰ Time: NTP syncs automatically every 30 min. Use "Force NTP Sync" or set manually with format: YYYY-MM-DD HH:MM:SS

📅 Schedules: MWF = Mon/Wed/Fri, TTh = Tue/Thu. Add bells with hour (0-23), minute (0-59), and track (1-7).

🎯 Events: Enable event mode to override normal schedule during specified date range.

🔧 Troubleshooting: Check WiFi status, RTC health, and logs for issues. Restart if needed.

📝 SD Card: Files must be named 0001.mp3, 0002.mp3, etc. in FAT32 format.
